Privacy Policy

Rclone Model Backup is a personal-use application operated by the Google account owner.

Google Drive Access

The application uses Google Drive authorization to upload, verify, and manage backup files created by this application.

Data Processing

File transfers may run on the owner's computer or in a Google Colab environment. Files are transferred between their source and the owner's Google Drive.

Credentials

OAuth credentials are stored in the owner's controlled environment and are not included in this public website.

Data Sharing

The application does not intentionally sell or disclose Google Drive user data to unrelated third parties.

Access Revocation

The account owner can revoke this application's Google access through Google Account settings.
